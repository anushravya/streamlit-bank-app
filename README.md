# 🏦 Streamlit Bank Management System

A simple **Bank Management System** built using **Python**, **Object-Oriented Programming (OOP)**, and **Streamlit**. The application provides a user-friendly interface for performing basic banking operations while storing account information in a JSON file.

## 🚀 Features

- Create a new bank account
- Deposit money
- Withdraw money
- View account details
- Update account information
- Delete an account
- JSON-based data storage
- Interactive Streamlit web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Object-Oriented Programming (OOP)
- JSON

## 📂 Project Structure

```
Bank-Management-System/
│── app.py          # Streamlit application
│── hello.py        # Bank class and business logic
│── data.json       # Stores account data
│── requirements.txt
│── README.md
```

## ▶️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/streamlit-bank-app.git
```

2. Navigate to the project folder:

```bash
cd streamlit-bank-app
```

3. Install the required package:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```
